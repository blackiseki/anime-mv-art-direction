# 一页纸决策矩阵

打印出来，或贴进企划文档第一页。**每行只许选一个主项**（最多加一个副项）。选完，把"代价"一栏写上——写字比点头有效。

> 如果你只有十分钟：只做带 ★ 的六行。它们决定全片 70%。

## A 决定层（先定，决定后面全部）

| # | 维度 | 选项 | 我方选择 | 代价 |
|---|---|---|---|---|
| ★1 | **论点** | 一句话的世界规则（不是情绪）。见 `02-concept.md` 的 10 型机制 | | 换一首歌就不成立吗？ |

## 自查：六个致命组合

选完之后扫一眼，命中任意一条就是结构性问题：

| 组合 | 后果 |
|---|---|
| 高调（亮部多）+ 浅色歌词 | 文字消失 |
| 循环叙事 + 结尾淡出 | 循环被打断，"完成感"归零 |
| 无人物 + 全程中景 | 没有主体，也没有节奏 |
| 快剪密度 + 大量歌词 | 读不完 = 什么都没看到 |
| 3 天工期 + 逐帧手绘 | 做不完 |
| 独特世界 + 4 个以上场景 | 每个都建不深，变成地点游览 |
