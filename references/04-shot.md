## 1. 景别节奏

景别不是"随机变化"，是**句子结构**。同一段落里有语法，段落之间是递进。

| 景别 | 信息 | 情绪 | 在 MV 里的用法 |
|---|---|---|---|
| 大远景（人物占高 < 15%） | 世界、位置、孤独 | 渺小、命运、史诗 | Intro、间奏、副歌前的空地 |
| 全景 | 人物与空间的关系 | 处境 | 建立场景，一镜足够 |
| 中景（腰以上） | 动作、姿态 | 叙事 | 主体，用量最大 |
| 近景（胸以上） | 表情、情绪 | 亲近 | 歌词的"心里话" |
| 特写（脸） | 微表情 | 亲密/冲击 | 副歌重拍、转折 |
| 大特写（眼/手/唇/物件） | 细节、象征 | 极度私密或极度抽象 | 母题出现处、卡点 |

### 节奏公式
**段落内**：至少交替 3 种景别。全是中景 = 平。
**段落间**：景别要"跳级"——从大远景直接到特写（不经过全景），这种跳跃本身就是重音。

### 情绪映射（可直接用）
- 孤独 → 大远景 + 小人物 + 大面积空白
- 亲密 → 近景 + 浅景深
- 压迫 → 中景 + 顶格 + 环境挤满
- 释放 → 从特写拉到大远景（一镜之内）
- 失控 → 景别在 1 秒内连续跳 3 级

**数量参考**（3.5 分钟，BPM 128）：
- 大远景 10%
- 全景 15%
- 中景 35%
- 近景 25%
- 特写/大特写 15%

中景占比最高，但如果**超过 50%**，整片会变成"人物在说话"的平淡感。

## 2. 机位语义

机位的**高度**在编码权力与情绪，比角度本身更重要：

| 机位 | 效果 | 用在哪 |
|---|---|---|
| 极低（仰拍，地平线在下 1/5） | 英雄、压迫、巨大 | 副歌、觉醒、威胁 |
| 平视 | 平等、客观、日常 | 叙事主体（默认） |
| 略高 | 轻微俯视、被观察 | 不安的伏笔 |
| 高（俯拍） | 无助、被命运看 | 下坠、失败、孤独 |
| 顶拍（正上方） | 物化、仪式感、抽象 | 躺下的角色、地图感、母题展示 |
| 荷兰角（倾斜） | 失衡、疯狂、危险 | 只用一两次，多了廉价 |

**关键**：机位高度在全片要有**走向**。例如"从高到低"= 她越来越有力量；"从低到高"= 她越来越小。这个走向本身就是叙事，观众说不出但能感到。

## 3. 焦段

不用真的换镜头，只要在设计上区分三种"镜头感"：

| 焦段感 | 视觉特征 | 心理 |
|---|---|---|
| 广角（24mm 感） | 边缘拉伸、背景大、人物被环境吞 | 渺小、环境压倒人、眩晕 |
| 标准（50mm 感） | 接近肉眼 | 客观、日常 |
| 长焦（135mm+ 感） | 背景压缩、虚化强、人物被"贴"在背景上 | 孤立、被凝视、距离感 |

**MV 里的高效用法**：同一场景，Aメロ用广角（她在巨大的空间里），サビ换长焦（世界被压扁成背景，只剩她）。场景没变，情绪全变了。

## 4. 运动方向

**方向是隐形的叙事。**

| 方向 | 语义 |
|---|---|
| 左 → 右 | 前进、顺流、正常时间 |
| 右 → 左 | 回溯、逆行、反常 |
| 向上 | 上升、希望、解脱（或失重） |
| 向下 | 下坠、压迫、放弃 |
| 向观众（推近） | 逼近、侵入、亲密 |
| 远离观众（拉远） | 失去、抽离、结束 |

### 三条纪律
1. **同一段落内方向要一致。** 连续几个镜头都朝右，突然一个朝左 = 强重音（或失误，取决于你是否故意）。
2. **转折点可以整体反向。** Cメロ全部反向运镜，观众会感到"回不去了"，成本几乎为零。
3. **不要左摇右摇来回。** 会制造廉价感。

## 5. 构图

二次元 MV 跟实拍不同：**中心构图是常态，不是错误**。因为角色是绝对主体。

| 构图 | 效果 | 场景 |
|---|---|---|
| 中心 + 对称 | 仪式感、宿命、静止 | 副歌、标题、结尾 |
| 中心 + 大负空间 | 孤独、渺小、诗意 | 大远景、留白段落 |
| 偏置（1/3） | 有"去向"，画面有方向 | 行走、望向某处 |
| 顶格（头顶被切） | 压迫、被挤 | 焦虑、崩溃 |
| 压边（人物贴边） | 不安、想逃出画面 | 逃避、边缘感 |
| 遮挡（前景挡一半） | 偷窥、距离、层次 | 过渡、观察 |

**负空间纪律**：留白要**空得干净**（纯色/渐变/虚化），不能是"没画完的空白"。空得干净才叫留白，否则叫没做完。

## 6. 卡点换算

### 6.1 基础换算表（4/4 拍）

| BPM | 1 拍 | 1 小节(4拍) | 8分音符 | 16分音符 |
|---|---|---|---|---|
| 80 | 0.750s | 3.000s | 0.375s | 0.188s |
| 90 | 0.667s | 2.667s | 0.333s | 0.167s |
| 100 | 0.600s | 2.400s | 0.300s | 0.150s |
| 110 | 0.545s | 2.182s | 0.273s | 0.136s |
| 120 | 0.500s | 2.000s | 0.250s | 0.125s |
| 128 | 0.469s | 1.875s | 0.234s | 0.117s |
| 130 | 0.462s | 1.846s | 0.231s | 0.115s |
| 140 | 0.429s | 1.714s | 0.214s | 0.107s |
| 150 | 0.400s | 1.600s | 0.200s | 0.100s |
| 160 | 0.375s | 1.500s | 0.188s | 0.094s |
| 170 | 0.353s | 1.412s | 0.176s | 0.088s |
| 180 | 0.333s | 1.333s | 0.167s | 0.083s |

### 6.2 卡点层级

不是所有拍都值得切。层级越高，切点越"响"：

| 层级 | 位置 | 用途 |
|---|---|---|
| L1 强 | 小节第 1 拍（downbeat）、段落开头、冲击点 | 切镜、闪白、大字、画面跳变 |
| L2 中 | 第 2、4 拍（backbeat） | 常规切镜、动作节点 |
| L3 弱 | 8 分音符 | 快切段落、粒子爆发、文字跳字 |
| L4 极弱 | 16 分音符 | 只用于极端瞬间（抖屏、频闪），一次两秒为上限 |

### 6.3 剪辑密度参考（按段落）

| 段落 | 每镜时长 | 卡点层级 |
|---|---|---|
| Intro | 1–4 小节 | L1 |
| Aメロ | 1–2 小节 | L1/L2 |
| Bメロ | 1 拍–1 小节 | L2，末尾加速 |
| サビ | 1–2 拍 | L1/L2/L3 |
| 间奏 | 2–8 小节 | L1（可以长） |
| Cメロ | 2–4 小节 | L1（几乎不切） |
| ラスサビ | 半拍–1 拍 | L1/L2/L3 混 |
| Outro | 1–3 镜 | L1 |

**反直觉的建议**：**不要每拍都切。** 全程 1 拍一切会让观众麻木，副歌就不再"炸"。
正确做法：Aメロ 2 小节一切（慢），到 Bメロ 突然 1 拍一切（快），这个**加速本身**就是爆点，不需要更多特效。

### 6.4 没有音轨时
有 BPM 就用 §6.1 推算。没有 BPM 就边听边数，把每个小节的起始时间写下来（手动打点），误差 ±2 帧内可用。
**不要**用"平均分成 60 个镜头"这种方法——音乐会跟你作对。

## 7. 提前量

| 事件 | 提前量 | 原因 |
|---|---|---|
| 画面切点 | 提前 1–2 帧 | 人眼有约 40ms 感知延迟，正拍切会感觉"慢半拍" |
| 歌词出现 | 提前 0.15–0.25s | 观众要时间开始阅读，正好在唱到的那刻出现会来不及 |
| 特效爆发 | 正好在拍上（或提前 1 帧） | 特效是"结果"，要跟声音同时 |
| 黑场/闪白 | 正好在拍上 | 冲击类要与声音严格同步 |
| 段落转场 | 提前半拍 | 让观众有"要变了"的预感 |

## 8. hold：留白

**至少 3 个真正的 hold。** hold 的定义：画面在 2 秒以上**几乎没有变化**（可以有极慢的推、飘、呼吸）。

| 类型 | 做法 | 效果 |
|---|---|---|
| 静止帧 | 完全不动 1–3 秒 | 时间冻结、震撼、让观众消化 |
| 极慢推 | 2–4 秒推 5%，几乎看不出 | 呼吸感、凝视 |
| 黑场 | 0.5–2 秒全黑（保留音乐或全静音） | 分段、死亡、断裂 |
| 空镜 | 只有环境，无人物 2–4 秒 | 时间流逝、地点建立、情绪落地 |
| 抽掉特效 | 前面一直有粒子，突然全清 | 世界安静下来 |

**放在哪**：
1. 副歌前（溜め，制造期待）
2. Cメロ（全片最低点）
3. 结尾前（最后一个音之前）
4. 强冲击之后（让观众消化）

**最重要的 hold**：副歌前。这里给 1–2 秒的静止，副歌的冲击力会翻倍。这是全片性价比最高的 1 秒。

## 9. 竖屏（9:16）

竖屏不是"横屏裁一下"。构图法则整个换。

| 项 | 横屏 | 竖屏 |
|---|---|---|
| 主体占比 | 人物高 40–70% | 人物高 60–85% |
| 构图 | 横向三分 | 垂直分层：上（天/空）中（人物）下（地/前景） |
| 大远景 | 可用 | 慎用——人物会小到看不见 |
| 文字 | 侧边、底部 | 上半或下半，避开平台 UI（上下各 15%） |
| 字号 | 1080p 下 60–80px | 同尺寸下 ×1.5 |
| 细线 | 1–2px 可读 | 3px 以下会被压缩吃掉 |
| 横向运动 | 有空间 | 空间太小，改用纵向运动 |

**最常见错误**：把横屏分镜两侧裁掉交差。结果人物永远在中间一条，上下空白浪费，且原构图的重心全错。

**正确做法**：分镜阶段就用竖构图（或者在横屏分镜上标注"竖屏安全框：中间 56% 宽度"），关键信息全部落在安全框内。

## 10. 分镜表规范

用 `assets/shotlist.template.csv`。字段与填写要求：

| 字段 | 说明 | 必填 |
|---|---|---|
| `no` | 镜号，001 起 | ✓ |
| `start` / `end` | 时间码 `m:ss.ff`（fps 见项目设置） | ✓ |
| `dur` | 时长（秒，两位小数） | ✓ |
| `section` | 段落（Intro/Aメロ/Bメロ/サビ1/間奏/2番/Cメロ/ラスサビ/Outro） | ✓ |
| `lyric` | 该镜对应的歌词原文（无则填 `-`） | ✓ |
| `shot` | 景别（ELS/FS/MS/CU/ECU） | ✓ |
| `angle` | 机位（low/eye/high/top/dutch）+ 焦段感（w/std/t） | ✓ |
| `subject` | **画面里发生什么**（一句话，动词开头） | ✓ |
| `move` | 运镜（fix/pan/tilt/dolly/tracking/handheld/zoom） | ✓ |
| `trans` | 转场（cut/dissolve/wipe/iris/match/glitch/none） | ✓ |
| `beat` | 卡点层级（L1/L2/L3/L4） | ✓ |
| `fx` | 特效（从材质词汇里选，最多 2 个） | |
| `hold` | 是否为 hold（Y/N） | |
| `asset` | 素材来源（新画/复用/3D/AI/现成） | ✓ |
| `note` | 风险、待定、需用户拍板 | |

### 填写纪律
- `subject` **必须动词开头**（"她抬头"不是"她的脸"）。不写动词的分镜等于没写。
- `fx` 一镜最多 2 个。3 个以上要写理由，否则默认砍掉一个。
- `asset` 里"复用"的比例应 ≥ 40%，否则工期会超。
- 每 10 镜至少有 1 镜是 `hold: Y` 或长镜（>2.5s）。

### 校验
写完后跑：
```bash
python scripts/shotlist_check.py docs/SHOTLIST.csv --bpm 128 --fps 24
```
会检查：时间断点/重叠、时长与卡点是否对齐、景别分布是否单一、特效堆叠、hold 数量、复用比例、空字段。

## 11. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 看了没感觉 | 全程同一景别/同一强度 | 做景别跳级 + 加 hold |
| 节拍"差一点" | 用平均分配而不是真实拍点 | 重新对拍，切点提前 1–2 帧 |
| 副歌不够炸 | 前面没有留白 | 副歌前加 1–2 秒静止 |
| 像幻灯片 | 每镜都是固定画面 | 每镜至少给一个运动（极慢推也算） |
| 看不懂在发生什么 | 缺全景/建立镜头 | 每个新场景先给一个全景 |
| 越看越累 | 镜头太短且都有特效 | 拉长镜头、删特效、加空镜 |
| 竖屏版很难看 | 横屏裁切 | 重排竖构图 |
