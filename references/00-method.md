# 00 — 方法论：怎么当这支片子的导演

开头必读。这份讲**怎么想、怎么问、什么时候该拦住用户**；具体每个维度怎么做在 01–07。

Contents: 1 失败的真实原因 · 2 三次翻译 · 3 锁与收敛 · 4 矛盾表（全量）· 5 提问节奏 · 6 引导话术 · 7 诊断三问 · 8 交付节奏 · 9 什么时候该说"不"

## 1. 失败的真实原因

新手和熟手的差距通常不在"会不会画"，而在三件事上，且都发生在动手之前：

| 症状 | 真实原因 | 本 skill 的对应动作 |
|---|---|---|
| 每一镜都好看，连起来像素材拼接 | 没有论点，所以镜头之间只有"并列"没有"递进" | P1 逼出一句话 |
| 做到 60% 突然不知道该怎么继续 | 规则不足。前面靠感觉，感觉会用完 | P2 建立五条可执行的规则 |
| 成片"很用心但不好看" | 装饰盖住了结构：颜色多、特效多、信息多 | P4 砍，不是加 |
| 观众记不住任何一帧 | 没有母题重复，也没有招牌瞬间 | P1 选 6–10 个招牌瞬间 |
| 越改越乱 | 每次改动没有"宪法"可对照 | 每次改动回头查 VISUAL_BIBLE |

**核心判断**：MV 是一门**时间艺术**，不是 60 张独立插画。任何决定都要回答"它在第几秒、跟上一样东西是什么关系"。

## 2. 三次翻译

情绪 → 论点 → 系统 → 时间表。三次翻译的共同要求：**每次输出必须比输入更窄**。

- 情绪（无限）→ 论点（一句话）
- 论点（一句话）→ 五条规则（每条一句话 + 一个否决条件）
- 五条规则（五句话）→ 时间表（N 个镜头的具体参数）

如果某一层输出比输入更宽（比如论点写成了"表现青春的迷茫与希望"），就是翻译失败，退回上一层的输入重新压。

### 判据：规则必须能否决
写完一条规则，问："它能否决什么具体做法？"
- ❌ "整体偏冷色" → 不能否决任何东西（冷到什么程度？哪里可以暖？）
- ✅ "环境永远冷调，只有人物皮肤与光源保留暖调；出现第二种暖色即视为失误"

## 3. 锁与收敛

风格维度看起来有几十个（世界观、时间弧、键调、色板、母题、材质、线型、角色、字体、3D 角色、转场、结尾……），全排列是天文数字。但它们**不是独立的**，其中两个是"锁"：

**第一把锁：论点**（这支片子的视觉机制）
**第二把锁：世界与时间弧**（在哪儿、从什么状态走到什么状态）

这两把锁一合，下面这些基本自动收敛，只需微调：
- 色板（时间弧决定渐变方向）
- 明度键调（世界观决定：黄昏低键 / 正午高键）
- 材质（世界观决定：玻璃光 / 纸墨 / 水 / 静电）
- 母题（论点决定：什么形状能承载这个机制）
- 转场语法（材质决定：玻璃→碎裂，纸→翻页，水→扩散）
- 结尾（时间弧决定：回到起点 / 走向黎明 / 停在原地）

**用法**：当用户在某个细节上纠结超过 2 轮，说明锁没上。停下来回到 P1 补锁，不要在那个细节上继续讨论。

## 4. 矛盾表（全量）

每次用户给出组合，扫一遍这张表。命中就当场说，说的时候给**改法**而不只是问题。

### 4.1 情绪 vs 音乐
| 想要 | 冲突信号 | 判断与改法 |
|---|---|---|
| 燃 / 炸 | BPM < 90、小调慢板、大量留白 | 燃来自对比与加速度。把"燃"放在最后 30 秒，前面必须真的安静 |
| 燃 | 全程 160 BPM 快切 | 会疲劳，第 40 秒后观众开始麻木。每 30 秒必须给一次 2 拍以上的静止 |
| 悲伤 | 明亮高饱和色板 | 悲伤靠**明度低 + 饱和度被抽掉**，不是靠灰 |
| 悲伤 | 大量粒子光效 | 感动需要干净的画面。特效会稀释眼泪 |
| 温柔 | 大量运镜与转场 | 温柔 = 少动 + 长镜头 + 浅景深感 |
| 恐怖 / 不安 | 色彩太丰富的场景 | 不安来自**信息缺失**：大面积单色、负空间、不完整构图 |

### 4.2 风格 vs 手段
| 想要 | 冲突信号 | 判断与改法 |
|---|---|---|
| 手绘感 | 3D 渲染 + 描边后处理 | 手绘感在**线抖动（boil）、线宽变化、不闭合线、上色出线**，描边解决不了 |
| 高级 / 电影感 | 8 个以上颜色、每镜都有特效 | 高级 = 少色 + 强明度结构 + 一致的规则 |
| 赛博 / 未来 | 只是加霓虹色和故障 | 未来感来自**尺度与空旷**（巨大结构 + 渺小人物） |
| 复古 / 怀旧 | 4K 锐利画质 | 怀旧需要**信息损失**：颗粒、色偏、色差、轻微模糊 |
| 极简 | 每镜都塞歌词 | 极简是一种纪律：允许某些镜头完全没有文字 |
| 独特 | 参考三支同类的表层元素 | 独特来自论点。表层元素拼贴 = 可识别的模仿 |

### 4.3 发布场景 vs 画法
| 场景 | 冲突信号 | 判断与改法 |
|---|---|---|
| 手机竖屏 | 横构图大远景、密集字幕、4px 细线 | 竖构图 + 主体放大 + 字号 ×1.5；细线在压缩后会消失 |
| 手机竖屏 | 关键信息放在画面边缘 | 平台 UI 会盖住上下 15%。所有标题放中间 70% 高度 |
| 大屏 / 展会 | 全局低对比暗调 | 投影和会场光会吃掉暗部。提亮中间调 |
| 平台短片（15–30s） | 前 5 秒慢热铺垫 | 首 3 秒必须有钩子：最强的一帧 + 最强的音 |
| 静音刷到 | 靠歌词讲清一切 | 画面必须自带叙事，文字是加成不是主线 |

### 4.4 工期 vs 方案
| 工期 | 冲突信号 | 判断与改法 |
|---|---|---|
| 1–3 天 | 手绘逐帧 / 3D 场景 / 原创角色多姿态 | 用"静止画 + 运镜 + 特效层"做 60% 的镜头；角色只做 3–5 个姿态 |
| 1–2 周 | 超过 80 个镜头 | 每镜平均 < 1.5 秒会做不完且会乱。合并成 40–50 个 |
| 1 个月+ | 每镜都从零做 | 建资产库：一个背景复用 3–5 次，靠运镜/调色/前景区分 |

**通用提醒**：创作者总在低估"合成与修改"的时间。分镜工作量的经验值——**拍摄/绘制 : 合成调色 : 返修 ≈ 4 : 3 : 3**。

### 4.5 文字 vs 画面
| 冲突信号 | 判断与改法 |
|---|---|
| 歌词压在角色脸上 | 文字与脸是竞争关系。要么让角色让开，要么让文字退到侧带或背景层 |
| 浅色天空上放白字 | 必读性归零。换深色字、加暗角/色块托底、或改到天空之外 |
| 每个镜头都有字 | 文字密度也是一种节奏。至少 1/3 的镜头应当无字 |
| 衬线体配高速快切 | 衬线体的细节在 2 帧内读不完。快切用粗黑/无衬线 |
| 中文字幕按日文排版 | 中文单字信息量大，同样时长需要更少字数、更大字号 |

## 5. 提问节奏

**一次只问一个批次，最多 3 个问题。** 问题太多人会开始敷衍，敷衍出的答案是后面所有返工的根源。

| 批次 | 时机 | 问什么 | 目的 |
|---|---|---|---|
| 1 | 开场 | 曲名+时长；歌词或音轨；**一句话**：想让人感觉到什么 | 定基调，不涉及方案 |
| 2 | 拿到批次 1 后 | 参考作品（具体到哪一段/哪一帧）；落地工具+工期；发布场景 | 定边界 |
| 3 | P1 论点草稿之后 | 给 2–3 个论点候选，问哪个更像他要的（可混） | 让用户做**选择**而不是**创作** |
| 4 | P2 每个维度 | 2–3 个候选 + 推荐 + 代价 | 逐条收敛 |
| 5 | P3 分镜草案后 | 哪 3 个镜头是你最想保住的？ | 找真实优先级，砍别的 |

**不要问的问题**（问不出有效信息）：
- "你想要什么风格？"（太宽，用户会用形容词回答，形容词无法执行）
- "你有什么想法？"（把创作压力推回给已经卡住的人）
- "要不要加点特效？"（引导性且无信息）

**换成**：
- "更像 A（低饱和、长镜、克制）还是 B（高对比、快切、密集特效）？"
- "你希望观众记住的那一帧，是角色在做什么？"
- "如果只能保留一个视觉元素，你留哪个？"

## 6. 引导话术

### 6.1 给建议的标准句式
```
推荐：<选项>
因为：<它如何服务论点 / 如何解决某个具体问题>
代价：<选它会失去什么>
反例：<什么情况下不要选它>
```
四行，不多不少。少了"代价"就变成推销。

### 6.2 要在用户说"随便""都行"时
不要替他随便选。改成二选一，并给出"不选的那个会怎样"：
> "这两条都成立。但如果走 A，第 40 秒的副歌就只能靠调色撑，会比较平；走 B 会牺牲 A 的干净感但副歌更炸。你更怕哪一个？"

### 6.3 用户否定了所有候选时
说明批次 1 或批次 3 的信息是错的。不要临时造第四个候选——**回退**：
> "看来我理解的方向偏了。回到最开始：你说想要'被击中的感觉'——是像被突然吓到（惊吓型），还是慢慢累积到受不了（压力型）？这两种的画面完全不同。"
"被击中"是个含糊的词，拆成两种机制后就能选了。

### 6.4 用户已经做完了，只想被评审
跳过 P0–P1 的提问，直接读成片/分镜，用三栏输出：**保留 / 修 / 砍**，每项一句理由。然后指出**唯一一个**结构性问题（不要列十个），因为人一次只能改一件事。

## 7. 诊断三问

任何卡住的情况，问这三个问题。它们测的是结构而不是技法：

1. **这支片子最贵的一秒是哪里？**
   答不出来 → 没有高潮设计。回 P1 挑招牌瞬间。
2. **删掉哪一段，整支片子就不成立了？**
   答案是"哪段都能删" → 没有结构，只是并列的素材。回 P1 找"转折点"。
3. **第一帧和最后一帧是什么关系？**
   没关系 → 片子没有完成，只是结束了。设计一个 bookend（同样的构图，不同的状态）。

第三问特别有用：MV 的"完成感"90% 来自首尾呼应。哪怕只是同一个机位、同一个人、不同的天色。

## 8. 交付节奏

| 阶段 | 交付物 | 形式 | 长度上限 |
|---|---|---|---|
| P0 | `docs/BRIEF.md` | 半页 | 曲目信息 + 意象库 10 条 + 情绪一句话 |
| P1 | 论点候选 | 对话 | 2–3 个候选，每个一句话 + logline 两句话 |
| P2 | `docs/VISUAL_BIBLE.md` | 2–3 页 | 五条规则，每条含否决条件 |
| P3 | `docs/color_script.png` + `docs/SHOTLIST.csv` | 图 + 表 | 色卡随段落；分镜一行一镜 |
| P4 | 评审意见 | 对话 | 保留/修/砍三栏，每项一句 |

**落盘纪律**：所有阶段产物写进项目 `docs/`，不要只在对话里说。创作者第二天回来要能直接接手，也不该被迫翻聊天记录。

**每阶段结束的一句话总结**：
> "论点定了：『所有东西都在失去轮廓』。接下来定色彩——我会给你三套色板，你看哪套配这句话。"

带着下一阶段的预期收尾，用户才知道自己在流程的哪里。

## 9. 什么时候该说"不"

这个 skill 不是执行器。以下情况明确反对，并说明后果：

- **要求复制某支已有 MV 的视觉。** 可以拆解它的**方法**（怎么建立对比、怎么用母题），但不能复制它的**母题和色板**。理由：观众会立刻识别出出处，作品的全部价值归零。
- **要求用既有角色的相似形象**（发色+服装+配件组合高度接近某知名角色）。这是最实际的法律风险，也是二次元圈最不容忍的事。
- **要求"什么都加一点"。** 直接说：这样会得到一个每项都不成立的结果，然后给出二选一。
- **工期明显不够。** 不要说"尽力"，要给出**降级方案**：砍镜头数、砍 3D、砍原创资产，明确保住哪三件事。
- **用户要求跳过论点直接出分镜。** 可以先给，但标注"这是没有宪法的分镜，第 40 秒后大概率要重做"。
