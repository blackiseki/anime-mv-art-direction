## 1. 为什么是两个形状

大部分 MV 只用"氛围"不用"母题"。结果：每一镜都好看，但观众记不住任何东西。

母题的作用是给大脑一个**可追踪的对象**。一个就够建立秩序，两个才能建立**结构**（一个问，一个答）。

- **主形状**：承载论点，全片贯穿，面积/频率最大。
- **副形状**：与主形状对位（互补/冲突/包含），出现在转折点。

判据：**这两个形状之间要有关系**（圆里有方、方被圆切、线穿过圆）。没有关系的两个形状只是两个装饰。

---

## 2. 形状语义表

形状的联想有跨文化的稳定倾向（可以打破，但要刻意）：

| 形状 | 语义 | 适合 | 用在片中的方式 |
|---|---|---|---|
| 圆 | 完成、循环、宿命、温柔、光源 | 回忆、等待、归宿 | 太阳、灯、瞳孔、水纹、钟面、〇 |
| 方 | 制度、稳定、边界、禁锢 | 校园、日常、压抑 | 窗、门、黑板、房间、屏幕 |
| 三角 | 紧张、危险、方向、尖锐 | 冲突、下坠、警告 | 屋顶、碎片、箭头、远山、三角关系 |
| 线 | 联系、命运、时间、路径 | 思念、指引、告别 | 线、绳、轨、光、路、发丝 |
| 螺旋 | 迷乱、循环、递归、沉溺 | 眩晕、执念 | 漩涡、卷曲、云、耳鸣的视觉化 |
| 网格 | 控制、现代、秩序、无个性 | 都市、压抑、机械 | 窗格、铁塔、瓷砖、栅栏 |
| 波 | 情绪、不确定、流动 | 犹豫、波动、海 | 海、声波、旗、裙摆 |

**用法**：选主形状后，**在背景里放它**（窗是方的、云是圆的、地板是网格），在**转场里用它**（圆形擦除、线条划开），在**字体框架里用它**（矩形字块/圆形徽章）。

这是"看起来是一个作者做的"的秘密：结构层面反复出现同一个形状。

## 3. 母题的三次变形

母题如果三个段落都是同一个样子，观众第 2 次就无视它了。必须**变形**。

### 三幕变形公式
```
第一次（建立）：完整、小、不起眼，观众不觉得它有含义
第二次（变质）：它坏了 / 变了 / 被拿走，观众意识到"它有含义"
第三次（兑现）：它以另一种形态回来，含义被彻底改写
```

### 示例
- **圆形（光）**：夕阳 → 碎裂的月亮 → 她眼睛里的光
- **线（红绳）**：手腕上的绳 → 断了飘在空中 → 成为道路
- **方（房间）**：教室的窗 → 窗被雨糊住 → 她走出窗框，窗外是她自己画的窗

**关键**：第三次不能是"更好看的第一次"，必须是**含义翻转**。这是"母题回收"和"重复"的区别。

### 次数纪律
- 主母题全片出现 **3–6 次**。少于 3 次观众记不住，多于 6 次变啰嗦。
- 副母题 **2–3 次**，出现在转折点前后。
- 除了这两个，其他元素**不许重复**（否则观众会误以为它们也是母题）。

## 4. 母题要能承担转场

好母题是**免费转场**。转场在 MV 里是硬成本，用母题做转场几乎不花时间。

| 母题 | 免费转场 |
|---|---|
| 圆 | 圆形遮罩、虹膜、镜头穿过圆、眼睛特写接太阳 |
| 线 | 线条擦除（沿线的方向划开）、绳子甩过接下一镜、轨道延伸 |
| 方 | 翻窗、开门、屏幕切换、纸牌翻面 |
| 三角 | 碎片飞过、棱镜折射 |
| 水 | 波纹扩散、浸入水面（水下的下一镜） |

**做法**：写分镜时，凡是要转场的地方，先问"能不能用母题做一个 match cut"。能就用，不用额外设计。

## 5. 动件（motion prop）

静止画 MV 最大的问题是"不动"。最便宜的解法不是做动画，是给角色一个**会动的东西**。

常用动件与其含义：

| 动件 | 运动方式 | 情绪 |
|---|---|---|
| 长发 / 丝带 | 随风飘、被吹向一侧 | 自由、被带走、时间 |
| 围巾 / 裙摆 / 大衣 | 缓慢摆动 | 孤独、等待 |
| 耳机线 / 耳饰 | 微小晃动 | 内在世界、倾听 |
| 雨 / 雪 / 花瓣 / 灰烬 | 全画面下落 | 时间流逝、净化、埋葬 |
| 烟 / 呼吸 | 上升消散 | 短暂、生命 |
| 纸片 / 传单 / 书页 | 翻滚飞散 | 记忆、失控 |
| 风铃 / 挂饰 | 摆动发声 | 有人在（或没人） |

**纪律**：一个镜头里**只用一个动件**。同时飘头发、飘花瓣、下雨、飘灰，会变成"素材乱舞"。

**动件的方向 = 情绪的方向**：向左飘是"被留下"，向右飘是"向前走"，向上飘是"反常/失重/解脱"。

## 6. 世界观三条规则

一个 MV 的世界不需要解释，但必须**自洽**。自洽的标准：这个世界的物理、时间、社会各有一条规则，且在片中被展示过至少一次。

| 维度 | 规则示例 | 展示方式 |
|---|---|---|
| 物理 | 重力方向反了 / 水在天上 / 影子独立行动 | 一个镜头里明显违反 |
| 时间 | 没有夜晚 / 同一时刻重复 / 季节在一镜内变化 | 一个镜头里时间跳变 |
| 社会 | 没有别人 / 所有人戴面具 / 只有她能看见某个东西 | 一个镜头里展示"少了一个东西" |

**观众不需要被告知规则，但一旦你违反了它会察觉。** 所以规则一旦定了，全片不许破（除非破规则本身是设计）。

**最经济的自洽法**：只在**一个**维度上反常，其他全部正常。
- ✅ 世界完全写实，只有影子不跟着人（这一条就够撑一支片子）
- ❌ 重力反了 + 时间乱跳 + 颜色会说话（观众放弃理解）

## 7. 场景不是背景板

选场景的五个判据（按重要性）：

1. **它能承载主母题吗？** 有圆形的地方（太阳、月、钟、灯、水纹）比没有的地方强。
2. **它有天然光源吗？** 有光源才有明度结构。无光源的场景（阴天平地）会让画面塌。
3. **它能不能提供至少 3 个不同景别？** 一个能拍特写、中景、远景的地方，才值得建。
4. **它和角色的关系成立吗？** 她为什么会在这里？答不出就是"好看的空房间"。
5. **成本。** 一个场景建好后要复用 3–5 次才划算（靠不同机位/时间/前景区分）。

### 场景要"能进入"
好的场景有**前中后景**：前景（栏杆、树枝、人流）— 中景（角色）— 后景（天空、建筑）。
只有一层的场景（全屏插画）只能靠运镜假装深度，看久了会平。

**廉价的深度做法**：前景加一个模糊的遮挡物（栏杆/草/玻璃/雨），中景人物，后景渐变天空。三层一叠，立刻有空间。

### 场景数量
一支 3–4 分钟的 MV，**3–5 个场景**足够。超过 7 个，每个都建不深，最后变成"地点游览"。
极简型 MV 可以只有 **1 个场景**（一个房间/一个天台），靠时间与光变化撑全片——这是很高级的做法，但要求角色和光做得好。

## 8. 材质与线条语言

这是"风格"真正所在的地方，比色板更能决定"像不像手绘/像不像电影"。

### 8.1 线条

| 线型 | 感觉 | 做法要点 |
|---|---|---|
| 笔刷/毛笔 | 传统、力道、和风 | 线宽变化大，起笔收笔有顿挫 |
| 铅笔 | 私密、草稿、记忆 | 线不闭合、有重复描线、留灰 |
| 马克笔 | 流行、POP、活泼 | 粗细均匀、转角圆、可套色 |
| 无描边（色块） | 现代、平面、设计感 | 靠色块边界，边界要干净 |
| 蜡笔/粉笔 | 童稚、粗糙、温度 | 边缘毛糙，有颗粒缺口 |
| 木刻/版画 | 厚重、历史、宗教感 | 黑白强对比、刀痕方向一致 |

**关键技巧：线抖动（line boil）**。线条每隔 2–3 帧轻微位移，会产生"手绘活着"的感觉。这是把数字画面变成"手绘"的最有效手段，成本极低。
- 抖动幅度过大 = 抽搐；过小 = 看不出来。经验值：线宽的 5–10%。
- 静止画也可以做 boil（整张图轻微呼吸），立刻不像 PPT。

### 8.2 材质隐喻

**全片选一种材质作为"世界的质感"**，它会自然生成特效词汇：

| 材质 | 特效词汇 | 适合 |
|---|---|---|
| 玻璃与光 | 折射、碎裂、反光、残影、棱镜 | 脆弱、记忆、透明 |
| 纸与墨 | 翻页、渗墨、折痕、撕裂、套印偏移 | 日记、书信、成长 |
| 水与波纹 | 扩散、浸没、倒影、涟漪、折射 | 情绪、时间、遗忘 |
| 烟与雾 | 消散、遮蔽、流动、呼吸 | 短暂、不确定、梦 |
| 布与丝 | 飘动、缠绕、撕裂、编织 | 关系、束缚、温柔 |
| 静电与故障 | 撕裂、色差、扫描线、丢帧 | 现代、疏离、失真 |
| 花与植物 | 生长、枯萎、散落、缠绕 | 生命、时间、埋葬 |
| 机械与金属 | 齿轮、锈蚀、转动、火花 | 命运、重复、冰冷 |

**用法**：选了材质，转场、粒子、文字效果、背景纹理全部从这套词汇里选。这样全片质感统一，且不需要每次重新想特效。
（详见 `06-craft.md` 的质感清单。）

### 8.3 质感三件套（几乎万能）
无论什么风格，这三样加在一起会立刻提升"完成度"：
1. **颗粒**（1–4%，随明度变化）
2. **轻微色差**（边缘 0.3–1px 的 RGB 分离）
3. **暗角**（5–15%，柔和）

它们模拟的是"镜头/胶片"的物理损耗，观众感知为"这是影像，不是 PPT"。

## 9. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 每镜都好看但记不住 | 无母题，或无变形 | 选一个形状，全片 3–6 次，第三次翻转含义 |
| 像"素材拼贴" | 场景之间无空间关系 | 定 3–5 个场景，让角色在它们之间"移动" |
| 画面平 | 无前中后景 | 加前景遮挡物 |
| "AI 感" | 线条过于均匀、无 boil、无颗粒 | 加线抖动 + 颗粒 + 破坏对称 |
| 风格不统一 | 材质隐喻混用（一会儿纸一会儿金属） | 全片锁一种材质 |
| 世界观莫名其妙 | 反常维度超过一个 | 只保留一个反常，其余写实 |
| 动件乱飞 | 一镜多个动件 | 一镜一动件 |
