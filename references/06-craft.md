## 1. 转场是标点

硬切是默认，其他转场是**标点符号**——用错了就像写文章每句都用感叹号。

| 转场 | 标点 | 含义 | 用的时候 |
|---|---|---|---|
| cut 硬切 | 句号 | 下一件事 | 90% 的情况 |
| dissolve 叠化 | 逗号 | 时间流逝、地点关联 | 抒情、回忆、时间跳 |
| fade to black 黑场 | 分段 | 断裂、结束、死亡 | 段落之间，全片 ≤3 次 |
| fade to white 白场 | 破折号 | 冲击、失忆、升华 | 全片 1–2 次 |
| wipe 擦除 | 强调 | 空间移动 | 沿运动方向擦，别乱擦 |
| iris 圆形遮罩 | 冒号 | 聚焦、结束 | 和圆形母题配合 |
| match cut 匹配切 | 顿号（但很高级） | 两个东西是同一件事 | 招牌瞬间 |
| glitch 故障 | 删除线 | 系统错误、失真 | 现代/赛博，少用 |
| whip pan 甩镜 | 感叹号 | 速度、失控 | 快切段落 |
| 母题转场 | — | 用形状/材质做擦除 | 免费，优先用 |

**核心提醒**：新手喜欢用转场制造"技巧感"。观众不会因为一个漂亮的转场记住你的片子，但会因为**每个镜头都在转场**而感到累。

---

## 2. 转场预算

一支 3–4 分钟的 MV：

| 类型 | 数量上限 |
|---|---|
| 硬切 | 无限（默认） |
| 叠化 | 8–12 次 |
| 特殊转场（wipe/iris/glitch/whip/3D） | **≤ 8 次** |
| 黑场 | ≤ 3 次 |
| 白场 | ≤ 2 次 |

超了就是"技巧堆叠"，会稀释最该被记住的那几个。

**分配原则**：把最好的转场留给 6–10 个招牌瞬间，其余全部硬切。

## 3. match cut 四匹配

最高级也最便宜——它不花额外工时，只花**设计时的注意力**。

| 匹配维度 | 做法 | 例 |
|---|---|---|
| **形状** | 上一镜的形状 = 下一镜的形状 | 太阳（圆）→ 瞳孔（圆）→ 杯口（圆） |
| **运动** | 运动方向/速度一致 | 她向左转头 → 列车向左驶过 |
| **色彩** | 主色相同，内容全变 | 红色围巾 → 红色信号灯 |
| **构图位置** | 主体在画面同一位置 | 人物在左下 → 另一个物体在左下 |

**最有效的是"形状+运动"叠加**：上一镜她的手向上抬起 → 下一镜水面上的光向上浮起 → 观众感到一种说不出的连贯。

**怎么在分镜阶段就做出来**：写分镜时，把相邻两镜的 `subject` 并排读一遍，问"这两个画面有没有一个共同的形状/方向？"有就调整机位让它对齐。这一步只花 5 分钟，回报是整个片段的流畅感。

## 4. 动机转场

好的转场在画面内有**理由**：

| 动机 | 做法 |
|---|---|
| 被遮挡 | 前景一个东西扫过画面 → 遮挡的瞬间切 |
| 被照亮 | 闪光/开灯 → 亮的瞬间切 |
| 运动带出 | 镜头快速甩动 → 甩动的模糊里切 |
| 被吸入 | 镜头推进到某个洞/眼/字 → 切到新场景 |
| 声音触发 | 重拍/鼓点 → 画面跳变 |
| 人物动作 | 她闭眼 → 睁眼是新场景；她转身 → 转到新场景 |

**"人物动作驱动转场"是最自然的**，因为它符合观众的注意力路径。分镜时优先找这类机会。

## 5. 质感清单

分三档。**先做"必做"，再看工期决定进阶。**

### 必做（几乎万能，成本极低）
| 项 | 参数参考 | 作用 |
|---|---|---|
| 颗粒 grain | 1–4%，随明度反向（暗部多、亮部少） | 统一质感、防色带、去"AI 感" |
| 暗角 vignette | 5–15%，柔边 | 收拢视线、电影感 |
| 轻微色差 CA | 边缘 0.3–1px RGB 分离 | 镜头质感 |
| 统一调色 | 一次 LUT 或手调，把所有素材拉到同一白平衡 | 防"素材拼贴感" |
| 高光 bloom | 阈值 0.72–0.9，强度 10–25% | 光源呼吸感 |

### 进阶（决定"风格"）
| 项 | 作用 |
|---|---|
| 线抖动 boil | 手绘感的核心，2–3 帧一循环，幅度 = 线宽 5–10% |
| 纸纹 / 干刷 / 水彩边 | 手绘/绘本质感 |
| halftone 网点 / 套印偏移 | 印刷感、riso 风 |
| 扫描线 / 信号干扰 | 复古电子、赛博 |
| 色散 / 棱镜 | 玻璃材质词汇 |
| 光晕 / 耶稣光 | 神圣、希望、回忆 |

### 慎用（容易翻车）
| 项 | 风险 |
|---|---|
| 强镜头光晕 flares | 遮挡主体；多镜头重复会假 |
| 强 RGB 分离 | 超过 3px 就变成"故障片"，不再有情绪 |
| 故障条纹 | 与抒情内容严重冲突 |
| 连续白闪 | 不适感 + 平台压缩后死白；改**色闪** |
| 全屏粒子 | 稀释画面，且压缩后变噪点 |

**一条总原则**：所有质感都应该"几乎看不出来"。观众感觉到"好看"但说不出原因，才叫成功。能一眼看出"加了颗粒"就是加多了。

## 6. 压缩会毁掉什么

平台（B站/YouTube/抖音）都会**二次压缩**。它毁掉的东西必须提前防：

| 会被毁掉 | 原因 | 预防 |
|---|---|---|
| 暗部细节 | 低码率下暗部被量化成大色块 | 暗部至少留 3 档层次，不要放关键信息；提亮中间调 |
| 渐变（最容易） | 8bit 色深下大面积渐变必然起带 | 加 1–3% 颗粒抖动；避免大面积极平滑渐变 |
| 细线（1–2px） | 高频细节被抹掉 | 重要线宽 ≥ 3px；竖屏尤其注意 |
| 细密颗粒 | 被压成噪点块 | 颗粒不要过细过强，中频颗粒更耐压 |
| 纯黑 / 纯白 | 变成死黑死白 | 暗部 5–12%，亮部 ≤ 96% |
| 单帧闪白 | 被压成 2–3 帧的糊白 | 闪白至少 3 帧；或改色闪 |

**输出建议**（1080p 交付）：
- 编码 H.264 High Profile，CRF 18–20（或 12–20 Mbps）
- 上传用高码率母版，别先压到刚好
- 色彩空间 Rec.709，不要留未转换的 log/线性

## 7. 观看场景三测

成片（或分镜动画）做完，必须做三个测试：

### 测试 1：缩到手机大小看
把画面缩到手机上的实际尺寸（约 6 英寸，或直接在手机上看）。
- 主体还认得出吗？
- 文字还读得出吗？
- 细节是不是全糊成一团？

### 测试 2：静音看
关掉声音看一遍。
- 画面本身有没有叙事？
- 不看歌词能不能感到情绪走向？
- 如果有段落完全靠歌词才懂，那段画面就是弱的。

**为什么重要**：短视频平台上大量观众是静音刷到的。静音下画面必须成立。

### 测试 3：看前 3 秒
只看前 3 秒，然后问自己："会继续看吗？"
- 如果前 3 秒是 logo、黑屏倒计时、缓慢淡入 → **改**。
- 前 3 秒应该是最强的一帧、一个动作、或者标题直接砸出来。

---

## 8. 首 3 秒

这是全片 ROI 最高也最常被浪费的 3 秒。

| 做法 | 效果 |
|---|---|
| 最强的一帧（招牌瞬间的前 3 秒） | 最好 |
| 一个动作正在发生（她的手正伸出去） | 好，制造疑问 |
| 标题/キメ字直接砸出 | 好，记忆点前置 |
| 黑屏 + 环境音 | 只适合有品牌信任的创作者 |
| 缓慢淡入 | ❌ 短视频平台直接划走 |
| logo 动画 | ❌ 除非你是知名社团 |

**技巧**：把全片最好的一帧放在第 0 秒，然后在 2–3 秒后切走。观众带着"那是什么"的疑问继续看，这个疑问会撑过 Intro。

## 9. 输出规格

在企划阶段就把交付规格写进 VISUAL_BIBLE，避免做完才发现要重排：

| 项 | 建议 |
|---|---|
| 主版 | 1920×1080，24 或 30 fps（与拍摄/绘制帧率一致） |
| 竖版 | 1080×1920，**重新构图**，不是裁切（见 `04-shot.md` §9） |
| 帧率 | 24fps 有"电影感"，30fps 更"流畅/视频感"。二次元手绘多用 24 |
| 时长 | 与音轨完全一致，尾巴留 0.3–0.5s 静音 |
| 字幕文件 | 另外导出 .srt/.ass（平台字幕/翻译用），不要只烧在画面里 |
| 封面 | 单独做一张竖版封面（16:9 的和 9:16 的各一张） |
| 署名 | 片头 lockup + 片尾 credits，字体也在授权范围内 |

**封面常被忽略**：封面的点击率比正片质量更影响播放量。设计封面时用**最高对比的一帧 + 大字**，不要用"氛围很美但看不清是什么"的画面。
