# 05 — 字体声部：文字是这支片子的第二个声音

Contents: 1 四层声部 · 2 字体性格表 · 3 语种与字形 · 4 文字与角色的层级 · 5 竖排 · 6 动态字体的八个基本动作 · 7 可读性算术 · 8 排版与留白 · 9 授权 · 10 常见失败

---

## 1. 四层声部

不要"选一个好看的字体"。文字在 MV 里有四个功能层，每层有自己的性格：

| 层 | 内容 | 出现频率 | 性格要求 |
|---|---|---|---|
| L1 标题/署名 | 片名、artist、credits | 首尾各一次 | 有个性，是设计的一部分 |
| L2 歌词 | 主体文字 | 全片持续 | 可读性优先，性格次之 |
| L3 强调 | キメ字、单个大字、断句 | 6–10 次 | 极端（最粗/最细/最怪） |
| L4 装饰/UI | HUD、编号、拟声、界面 | 点缀 | 功能感、机械感 |

**纪律：全片字体家族 ≤ 3 个。** 通常是「一个衬线（L2）+ 一个极粗无衬线（L1/L3）+ 一个特殊（L4 或手写）」。

超过 3 个家族，画面会变成字体样品页。

## 2. 字体性格表

| 类型 | 感觉 | 适合段落 | 不适合 |
|---|---|---|---|
| 明朝 / 宋体 | 文学、哀感、时间、传统、细腻 | Aメロ、Cメロ、抒情、回忆 | 快切、爆发、电子 |
| 黑体（中粗） | 现代、中性、日常 | 通用歌词层 | 需要强性格时 |
| 极粗黑体 | 冲击、力量、宣言 | サビ キメ、标题 | 长句、抒情 |
| 圆体 | 可爱、温和、亲近 | 明快曲、日常、童趣 | 严肃、恐怖 |
| 手写 / 笔迹 | 私密、日记、记忆、脆弱 | 「心里话」、回忆段 | 副歌爆发（除非刻意对比） |
| 毛笔 / 楷 | 传统、庄重、和风 | 和风、宗教感、决意 | 现代都市 |
| 等宽 / 像素 / LED | 机械、数据、疏离、未来 | HUD、赛博、距离感 | 温情段落 |
| 超细体 | 冷静、疏离、高级 | 极简 MV、留白段 | 小尺寸（会消失） |

**最有效的一组对比**：明朝（细、抒情）＋ 极粗黑体（重、冲击）。
副歌把同一句歌词从明朝换成极粗黑体，情绪立刻从"低语"变"喊出来"——不需要任何特效。

## 3. 语种与字形

### 日文
- 假名多、字形圆润，**竖排（縦組み）**在日本 MV 里是常态而非特殊处理，尤其抒情曲。
- 明朝体的假名有"文语感"，配抒情极合适；黑体更"现代/流行"。
- 汉字与假名混排时，注意行距（假名需要更多呼吸）。
- 常用字符集：JIS 第一水准即可覆盖歌词；但要注意旧字体/异体字（歌手爱用）。

### 中文
- **单字信息量比日文高**（一个汉字 ≈ 2–3 个假名）。同样时长，中文要**更少字数、更大字号**。
- 不要用日文字体排中文：会缺字（显示成方框）或字形不对（如"直""骨""者"的差异）。
- 可用免费商用：思源黑体 / 思源宋体（Source Han）、霞鹜文楷、阿里巴巴普惠体等。**用前确认授权条款**。
- 中文宋体在小尺寸下笔画会糊，做竖屏尤其明显 → 用黑体或加粗。

### 中英混排（很常见）
- 拉丁字体与中日文字体的**基线/字重不匹配**是主要问题。混排时让拉丁字略小（90%），并统一字重。
- 英文全大写 + 字距加宽（tracking 5–10%）是"设计感"最快的来源。

## 4. 文字与角色的层级

这是二次元 MV 最有辨识度的手法。文字有三个 Z 位置：

### 4.1 文字在角色**后面**（背景层）
**效果最强**，是最像"MV"的做法。角色剪影清晰地压在巨大的字上，字成为环境。
- 适合：副歌、キメ、标题
- 要求：字要足够大（占画面高 60% 以上），且角色边缘要清楚
- 变体：字被角色挡住一部分（真实的遮挡关系比"半透明"高级十倍）

### 4.2 文字在角色**前面**（前景层）
- 适合：文字穿过画面、拟声、HUD、装饰性字形
- 注意：不要挡住脸和关键表情

### 4.3 文字与角色**同层**（侧带/上下）
- 最安全、最常用。歌词在画面一侧或底部，角色占主区。
- 适合：Aメロ、叙事段

### 4.4 文字**成为空间**
字足够大、有透视、有前后关系时，字就是建筑（穿过字的隧道、字的墙、站在字上）。成本高但记忆度极高，一支片子里用一次就够。

### 层级纪律
- **脸是禁区。** 任何情况下不压脸，除非是刻意的"文字压脸"设计（要用得非常狠，且只用一次）。
- 文字层级在分镜阶段就标注（`note` 字段写 `text:behind` / `text:front` / `text:side`）。
- 不要在同一条歌词上同时用两种层级（会让观众眼睛分裂）。

## 5. 竖排

竖排不是"把横排转 90 度"，它有自己的规则：

| 项 | 规则 |
|---|---|
| 阅读方向 | 从上到下，行从右到左 |
| 长音符号「ー」 | 竖排时变为竖线 |
| 小字（っゃゅょ） | 位置在右上（竖排时相对偏移） |
| 括号 | 竖排专用括号「」（）需旋转 |
| 拉丁字母 | 竖排里的英文通常旋转 90° 或整词横排（选择要全片统一） |
| 数字 | 通常保持正立（不旋转），或转 90°——全片统一 |

**为什么用竖排**：竖排的视觉重量是"从上落下"，天然带"落下/倾泻/命运"的感觉。中文/日文 MV 抒情段用竖排，比横排高级一档。

**陷阱**：竖排的行距要比横排大 10–15%，否则字会挤成一团。

## 6. 动态字体的八个基本动作

文字的**运动方式**也是字体设计。选 2–3 种作为全片语法，不要八种都用：

| 动作 | 做法 | 感觉 | 适合 |
|---|---|---|---|
| 逐字浮现 | 一个字一个字出现（0.05–0.12s 间隔） | 私密、时间流逝、倾诉 | Aメロ、独白 |
| 冲击放大 | 整块字从 80% 弹到 105% 再回 100% | 力量、重拍 | サビ キメ |
| 位移入场 | 从画面外快速滑入 | 速度、现代 | 快切段 |
| 遮罩揭示 | 用形状/线条擦开文字 | 克制、设计感 | 高级感段落 |
| 抖动/错位 | 单字轻微位移、RGB 分离 | 不安、故障、情绪崩 | 高压段落 |
| 空间运动 | 字在 3D 空间里旋转/穿行 | 空间感、史诗 | 间奏、招牌瞬间 |
| 遮挡互动 | 角色/物体从字前经过 | 层次、真实感 | 副歌英雄镜 |
| 整块字卡 | 一块实心卡片出现 3–8 帧 | 分段、断句、呼吸 | 段落切换 |

**最重要的一个**：**节奏不齐。** 文字的动画节奏不要跟每个字都均匀，要让"关键词"慢下来、其他快过去。均匀的文字动画看起来像模板。

## 7. 可读性算术

观众能读的速度大约是：
- **日文：每秒 4–6 个假名/汉字混排字符**
- **中文：每秒 3–5 个汉字**
- **英文：每秒 3–4 个单词**

所以一句歌词在屏幕上的**总停留时间** ≥ 字数 ÷ 上述速度。

例：中文 12 个字的句子 → 至少 12 ÷ 4 = **3 秒**；如果只有 1.5 秒，必须**拆成两次出现**，或者只保留关键词。

**三个救急手段**（当文字来不及读）：
1. 拆句（分两次出现，跟着唱）
2. 减字（只留关键词，其余不显示）
3. 加大字号 + 减少装饰（视觉阻力变小）

**检验法**：把成片静音看一遍。如果某句歌词你读不完就被切掉了，观众也没读完。

## 8. 排版与留白

- **字距**：大字距（+10–20%）= 高级、冷静、慢；紧字距 = 密集、急促。
- **行距**：1.15–1.5 倍。竖排 1.3–1.7 倍。
- **对齐**：全片统一。左对齐/居中/竖排右起——不要一镜一个对齐方式。
- **边距**：文字距画面边缘至少 5%（竖屏 8%），避免被平台 UI 和裁切吃掉。
- **文字周围的留白**：文字区要"清场"（纯色/虚化/暗角），不要在复杂画面上硬放字。

## 9. 授权

**在企划阶段就记进 VISUAL_BIBLE。**

| 类型 | 注意 |
|---|---|
| 系统字体 | 通常**不能**嵌入商用视频（Windows/macOS 自带字体授权限制） |
| 免费商用 | 思源系列、阿里巴巴普惠体、霞鹜文楷、Google Fonts（逐个看条款） |
| 商业字体 | 需购买**视频/影视**授权，个人版授权通常不覆盖 MV 发布 |
| 字体厂商的"个人免费" | 通常只限个人非商业；有广告分成/MV 投稿可能被认定商业 |

**提醒用户**：MV 一旦上平台并有收益（充电、广告分成、平台激励），字体的"个人使用"授权很可能不覆盖。这是真实的法律风险，不是杞人忧天。

## 10. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 文字"浮"在画面上 | 没有遮挡关系、没有明暗对比 | 让角色/前景挡住一部分；加深色托底 |
| 文字看不清 | 浅底浅字 / 太细 / 有纹理背景 | 换深色字、加粗、文字区清场 |
| 文字很土 | 默认字体 + 默认描边 + 居中 | 换字体、去描边（改用阴影或色块）、改对齐 |
| 像 PPT | 文字匀速淡入淡出 | 用逐字浮现 / 冲击放大 / 遮罩揭示 |
| 太花 | 4 种字体 + 每个字都动 | 砍到 ≤3 家族，只让关键词动 |
| 中文显示方框 | 用了日文字体排中文 | 换中文字体（思源系列） |
| 竖排很挤 | 行距没加大 | 竖排行距 ×1.15 |
